### 📖 简介

## **Painter Nodes** 是一个为 ComfyUI 设计的综合性自定义节点合集，专为高级图像和视频生成工作流打造。本插件目前包集成了多个强大的节点（后续新增节点都会放进此整合包），涵盖图生视频、文生视频，视频编辑，视频配音，参考生视频，文生图、图片编辑、音频驱动视频生成、视频对口型等功能。

## ✨更新日志：


 2026-9-24更新

 新增PainterVideoCombine2节点（显示名 Painter Video Combine 2）：在 PainterVideoCombine 的基础上，于节点第一行（images 行）水平居中加了两个小图标按钮——⟳「同步预览」和 ⏸/▶「同步暂停／继续播放」。同步预览＝右键菜单 Sync preview 的同款行为（工作区内所有 Painter 预览视频回到起点重播，动图刷新重播）；同步暂停会让工作区所有预览视频一起暂停，按钮变红并切换成播放图标，再点一次一起继续播。按钮是独立的 DOM 覆盖层，不新增 widget、不改变节点尺寸与排版，节点拉宽拉窄都保持居中，并且在 ComfyUI 的 Nodes 2.0（Vue 节点）渲染模式下同样可用。原 PainterVideoCombine 节点保持不变。

 2026-9-22更新

 新增PainterSizeSettings节点（显示名 Painter H3 Size Settings）：把参考生视频工作流里的“尺寸设置”子工作流转成独立节点，省掉一层子工作流。宽高比固定两项 16:9 (Widescreen) / 9:16 (Portrait)，默认 16:9；分辨率共 9 档并随宽高比自动切换：16:9 是 512*288 / 800*448 / 960*544 / 1024*576 / 1280*736 / 1376*768 / 1536*864 / 1600*896 / 1920*1088，默认 1376*768；切到 9:16 时同一档自动翻成竖版（1376*768 → 768*1376，也就是竖版默认），不会重置回第一项。时长默认 5 秒，左右三角每点一次 ±1 秒，也可以直接手动输入 5.1 / 5.3 这类小数；帧数沿用原公式换算，24fps 取整后对齐到 17k+5（5 秒 = 124 帧、5.3 秒 = 141 帧、6 秒 = 158 帧）。输出：宽度 / 高度 / 帧数，其中帧数可直接接 PainterMiniMaxRefToVideo6 的 length。

 2026-9-20更新

 新增PainterQwenImage21节点：适配 Qwen Image 2.1（基于官方 TextEncodeQwenImage21 优化）。参考图缩放一次、视觉塔与 VAE 两路复用，一次性输出 正条件/负条件/latent；无需输入负向提示词，负向条件由正向条件零化得到（结构与正向完全一致）；宽、高、批次集中在节点底部，输出尺寸 32 倍数对齐，第 1 张参考图作为编辑基准，其余参考图按同尺度等比缩放，最多 16 张参考图。注意：需要 ComfyUI 0.36 以上版本，以及 Qwen Image 2.1 专用的 DiT、VAE（64 通道）与 Qwen3-VL-8B 文本编码器，旧版 2509/2511/2512 的权重不适用。

### 🚀 安装方法

#### 方法 1：手动安装

1. 从 Releases 页面下载最新版本
2. 将 `Painter-Nodes` 文件夹解压到 ComfyUI 的 custom_nodes 目录：
   ```
   ComfyUI/
   └── custom_nodes/
       └── Painter-Nodes/
         
   ```

3. 安装依赖：
   ```bash
   cd ComfyUI/custom_nodes/Painter-Nodes
   pip install -r requirements.txt
   ```

4. 重启 ComfyUI

#### 方法 2：ComfyUI-Manager

在 ComfyUI-Manager 中搜索 "PainterNodes" 直接安装。
